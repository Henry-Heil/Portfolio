Takeaways:

  • amenities should be separated into columns, one for each amenity listed, and the same for pets_allowed.

  • Most categorical variables should be made into factors, bedroom and bathroom should be made numerical

  • Note that “DC” is one value in the state variable, which is reasonable

  • There’s a glitch in the RentCafe values in source due to text formatting

  • price and square_feet are extremely right-skewed, which can be corrected with logarithmic transformation

  • Three price_type values are weekly instead of monthly. Converting their prices by multiplying by 52/12 seems reasonable. One price is in the enigmatic “Monthly|Weekly” format and seems discardable.

We start by fixing price_type.

Fixing weekly prices

aptDataWorking <- aptDataWorking %>%
  mutate(price = if_else(price_type == "Weekly", (price*52)/12, price)
  ) %>%
  mutate(price_type = if_else(price_type == "Weekly", "Monthly", price_type))
aptDataWorking <- filter(aptDataWorking, price_type != "Monthly|Weekly")

Discarding unwanted variables

We probably can’t use:

  • price_type (now the same for all individuals)

  • USD (also same for all individuals)

  • title: looks like mostly just basic info (bedrooms) and address, we already have that information stored elsewhere

  • body: massive block of text which we won’t have the tools to analyze until we take DATA 322

  • address: again, we don’t have tools to analyze text, and there isn’t any real information contained here

  • time: seems to describe hour of day ad was accessed, not useful

  • price_display: just a less useful version of price (can use ggplot commands to display nicely)

  • id (contains no information)

We also remove pets_allowed, as it wasn’t important for any of our research questions and contains many NA values.

aptDataWorking <- select(aptDataWorking, -price_type, -title, -body, -time, -price_display, -address, -currency, -id, -pets_allowed)

Separating amenities

Each value in amenities is a comma-separated list of different amenities (gym, dishwasher, pool, etc). The code below creates a column for each amenity, which contains the TRUE boolean if an observation has that amenity listed in amenities. To ensure all amenities were covered, the copy amenities1 of amenities was created, and separated into 20 columns, each containing one amenity (observations with less than 20 amenities have some columns filled with NA), which were all read with unique to obtain examples of all possible amenities values.

aptDataWorking <- aptDataWorking %>%
  mutate(amenities1 = amenities) %>%
  separate(amenities1, into=c("am1", "am2", "am3", "am4", "am5", "am6", "am7", "am8", "am9", "am10", "am11", "am12", "am13", "am14", "am15", "am16", "am17", "am18", "am19", "am20"), sep=",")

Changing RENTCaf to RENTCafe

aptDataWorking <- aptDataWorking %>%
  mutate(source = if_else(source == "RENTCaf\xe9", "RENTCafe", source)
  )

What should be “RENTCafe” is instead “RENTCaf”, presumably because of an inability to display a character with an accent mark. This replaces the accented e in every instance of “RENTCafe” in source with a regular e.
